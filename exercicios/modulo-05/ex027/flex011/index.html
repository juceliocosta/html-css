Propriedade (shorthand) flex

Podemos indicar na mesma linha os valores de flex: grow shrink basis;


flex: flex-grow, flex-shrink, flex-basis

flex: ;

flex: ;

flex: ;

flex-shrink indica se os item podem ou não(0) encolher. padrão 1

flex-grow indica se os item podem ou não(0) crescer. padrão 0

obs.: irá se ajustar se o elemento pai tiver sua FlexBox nowrap

Propriedade resumida

flex: initial; equivale à flex: 0 1 auto; por ser o valor padrão do flex, podemos omitir

flex: none equivale à flex: 0 0 auto;. O menos flexível

flex: auto equivale à flex: 1 1 auto;. O mais flexível
